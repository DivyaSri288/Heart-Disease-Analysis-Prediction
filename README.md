# Heart-Disease-Analysis-Prediction
# Heart Disease Analysis and Prediction using Data Science and Data Engineering

## Project Overview

This project focuses on analyzing heart disease patient data using
Data Science and Data Engineering techniques.

## Technologies Used

- Python
- Pandas
- Jupyter Notebook
- Tableau
- CSV Dataset

## Project Workflow

1. Data Collection
2. Data Preprocessing
3. Data Transformation
4. Exploratory Data Analysis
5. Data Visualization
6. Machine Learning Model Development
7. Model Evaluation
8. Tableau Dashboard

## Dataset

The project uses the Cleveland heart disease dataset containing
patient-related attributes such as age, sex, chest pain type,
cholesterol, resting blood pressure, maximum heart rate,
exercise-induced angina and target.

## Data Analysis

The dataset was analyzed to identify patterns and relationships
between patient attributes and heart disease.

## Visualizations

Tableau was used to create visualizations for:

- Age Distribution
- Gender Distribution
- Cholesterol Distribution
- Heart Disease by Chest Pain Type
- Exercise Angina Distribution

## Machine Learning

Random Forest was used for heart disease prediction.

Model evaluation metrics include:

- Accuracy
- Precision
- Recall
- F1 Score

## Dashboard

An interactive Tableau dashboard was created to present
important heart disease insights and visualizations.

## Project Outcome

The project demonstrates how healthcare data can be processed,
analyzed and visualized to identify meaningful patterns related
to heart disease.
